    おなじのつなぎ API リファレンス

    モジュール

    application/decode-reference-corpus

    未知のJSONを原本参照コーパスとして厳格にデコードする。

    application/generate-worksheet-use-case

    未検証入力のparseからWorksheet生成までを一つのapplicationユースケースとして提供する。

    application/generation-error-message

    applicationとdomainで発生した既知の生成失敗を、画面表示用の日本語へ変換する。

    application/generation-worker-contract

    Worksheet生成Web WorkerとReact UIの間で交換するメッセージ型を定義する。

    application/parse-generation-request

    フォームやWorkerから届く未知の値を、domainのGenerationRequestへ厳格変換する。

    domain/generation/analyze-difficulty

    Puzzleとsolver計測値から、問題構造に基づく難易度指標を集計する。

    domain/generation/build-unique-path-cover

    盤面全体を覆う経路を先に組み立て、作問用のpath plan候補を生成する。

    domain/generation/generate-worksheet

    solution-first作問、独立solver、最適化、品質gateを統括してWorksheetを生成する。

    domain/generation/materialize-path-plan

    抽象的なpath planへ端点ID、記号、route roleを割り当てる。

    domain/generation/random

    seedから再現可能な疑似乱数と安定hashを提供する。

    domain/grid/adjacency

    長方形盤面上の上下左右の隣接セルを、決定的な順序で列挙する。

    domain/grid/coordinates

    セル座標、一次元index、文字列keyの相互変換と基礎的な距離計算を提供する。

    domain/solver/enumerate-pairings

    同じ記号を持つ端点について、partner候補と完全matchingを列挙する。

    domain/solver/normalize-solution

    経路の向きと列挙順に依存しないSolutionの正規形と識別keyを作る。

    domain/solver/optimize-solution

    有効な端点接続を完全探索し、経路形状costが最小のSolutionを選ぶ。

    domain/solver/residual-reachability

    経路探索途中の残余盤面をBigInt bitsetで表し、到達可能性を判定する。

    domain/solver/search-grid

    solverとoptimizerが共有する盤面探索状態、端点順序、枝刈り判定を提供する。

    domain/solver/solve-puzzle

    Puzzleの端点情報だけから、partner選択を含む全ての有効解を探索する。

    domain/types/difficulty

    問題構造から求める難易度レベルと、その分析根拠の型を定義する。

    domain/types/generation

    Worksheet生成要求、候補棄却理由、生成失敗を表すdomain型を定義する。

    domain/types/puzzle

    盤面、セル、端点、記号、端点profileというPuzzleの中心的なdomain型を定義する。

    domain/types/reference-corpus

    原本参照コーパスの出典、盤面転記、照合状態を表す型を定義する。

    domain/types/solution

    解答経路、Solution、solver結果、探索計測値、形状costの型を定義する。

    domain/types/worksheet

    生成済み問題、Worksheet、来歴、機械検査、人間向け説明材料の型を定義する。

    domain/validation/analyze-solution-coverage

    Solutionが使用するセル数と盤面被覆率を集計する。

    domain/validation/analyze-solution-geometry

    Solutionの辺数、曲がり、U字、形状costを分析する。

    domain/validation/analyze-unique-path-cover-entry

    唯一解問題の取っ掛かり、端点集中、pairing候補、経路干渉を分析する。

    domain/validation/explain-unique-path-cover

    唯一解問題の機械分析結果を、開発診断用の日本語説明へ変換する。

    domain/validation/run-machine-checks

    生成候補へ適用するvalidator、唯一解、profile、品質条件を一括実行する。

    domain/validation/solution-route-roles

    solverが見つけた解とsolution-first生成時のroute roleの対応を調べる。

    domain/validation/validate-puzzle

    Puzzle単体の寸法、端点ID、座標、記号個数などの不変条件を検査する。

    domain/validation/validate-solution

    Puzzleに対する任意のSolutionが、接続・隣接・非共有のルールを満たすか検査する。

    module

    「おなじのつなぎ」をSPA registryへ接続する遅延読込module。

    ui/AnswerPreview

    canonical solutionの解答線を含む、印刷用答案ページを描画する。

    ui/DeveloperDiagnostics

    生成来歴、機械gate、未実施の人間確認を開発者向けに表示する。

    ui/OnajiNoTsunagiPage

    生成条件入力、Web Worker実行、問題・解答previewを統括する教材画面。

    ui/PuzzleBoard

    Puzzleと任意のSolutionを、画面・印刷共通のSVG盤面として描画する。

    ui/ReferenceCorpusReviewPage

    原本参照JSONを読み込み、出典・転記状態・再描画盤面を開発者が確認する画面。

    ui/symbol-label

    domainの記号IDを、日本語表示とaccessibility用の名称へ変換する。

    ui/WorksheetPreview

    解答線を含まない問題用Worksheetを、画面previewとA4印刷向けに構成する。
