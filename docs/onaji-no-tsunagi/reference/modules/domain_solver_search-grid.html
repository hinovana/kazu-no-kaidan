    • domain/solver/search-grid

    モジュール domain/solver/search-grid

    solverとoptimizerが共有する盤面探索状態、端点順序、枝刈り判定を提供する。

    関数

    allTerminalsHaveReachablePartners

    各未接続端点に、残余盤面上で到達可能な同記号partnerがあるかを判定する。

    canEnterPathCell

    経路探索で候補セルへ進入できるかを判定する。

    createTerminalIndexSet

    Puzzleの全端点セルをrow-major indexのSetへ変換する。

    hasEvenSymbolParityInEveryComponent

    各残余連結成分で、記号ごとの未接続端点数が偶数かを判定する。

    sortTerminals

    端点をrow-major index、同一セルではterminalIdの順に整列する。

    terminalSearchStateKey

    占有maskと残存terminal集合から、失敗memo用の決定的な状態keyを作る。
