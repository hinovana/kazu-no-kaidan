    モジュール domain/generation/build-unique-path-cover

    盤面全体を覆う経路を先に組み立て、作問用のpath plan候補を生成する。

    このmoduleはsolution-first構成の公開入口であり、profile、経路候補、 exact-cover探索、記号割当の詳細を専用moduleへ委譲する。後段が 独立solverで検証できるよう、返却するPuzzleへ植え込みpartnerを含めない。

    関数

    buildUniquePathCover

    独立した低曲がり経路のexact coverをsolution-firstで構成し、端点化する。

    getSymbolAssignmentVariantCount

    profileのsymbolPathCountsを三記号へ割り当てる異なるvariant数を返す。

    getUniquePathCoverProfile

    profile IDに対応する読取専用の構成・品質gateを返す。

    selectUniquePathCoverProfileId

    難易度、Worksheet内の位置、問題数、request seedからprofileを決定する。
