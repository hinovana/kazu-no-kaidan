    モジュール domain/types/solution

    解答経路、Solution、solver結果、探索計測値、形状costの型を定義する。

    型だけでは解の有効性を保証せず、validation moduleによる検査を前提とする。

    インターフェイス

    PathGeometryAnalysis

    一本の経路について品質gateが参照する形状値。

    PathSolution

    同じ記号の二端点を結ぶ、向きを持つセル列。

    Solution

    全端点を結ぶ経路集合。

    SolutionCost

    optimizerが辞書式に比較する解のcost。

    SolutionCoverage

    盤面のうち解答経路が使用するセル数と比率。

    SolutionGeometryAnalysis

    canonical solution全体の経路形状と未使用セルの機械分析。

    SolverMetrics

    独立solverの探索量とsoundな枝刈りの適用回数。

    型エイリアス

    OptimizeSolutionResult

    cost最小化solverの探索結果。

    SolutionCount

    探索で判明した正規化解数。

    SolveResult

    独立solverの探索結果。
